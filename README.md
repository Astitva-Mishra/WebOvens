## Tech Stack & Architecture

This repository contains the codebase for the **WebOvens Agency Website**, engineered with:
- **Framework**: [Next.js 15](https://nextjs.org/) (App Router with Server/Client split optimization)
- **Runtime & UI**: [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Animation**: [Motion (Framer)](https://motion.dev/) for high-framerate, fluid spatial layouts and scroll-triggered manifests
- **Typography**: Editorial Serif & Technical Mono typography system
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis) for premium, kinetic scrolling physics
- **SEO & Semantics**: Built-in dynamic sitemap generation, structured JSON-LD data, metadata integration, and fully responsive accessibility paths.

## Running Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation & Launch

1. **Clone & Navigate:**
   ```bash
   git clone https://github.com/webovensin/webovens.git
   cd webovens
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory (you can copy the structure from `.env.example`):
   ```bash
   cp .env.example .env.local
   ```
   Add your keys:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
